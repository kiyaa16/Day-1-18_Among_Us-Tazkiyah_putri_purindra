rangkuman materi : 
materi 1
jurusan Tik memiliki visi menjadi jurusan bertaraf internasional dan memiliki 3 misi yaitu: pendidikan vokasi,riset,inovasi dan tata kelola digital
5 agenda: penguatan internal, kerja sama industri, pengembangan SDM, sarpras, dan inkubator bisnis.
Mitra: CCIT, MSU, Pemkot dan Dinkes Depok, Agate, Cisco, Huawei, Oracle, dan lainnya. Status MoU dan manfaatnya masih perlu dilengkapi.
materi 2
MBKM: hak belajar hingga 2 semester di luar prodi, dengan konversi sampai 20 SKS per semester kegiatan. Ada 8 bentuk kegiatan, seperti magang, riset, wirausaha, dan KKN.
MSIB: magang atau studi independen bersertifikat selama 1 semester bersama mitra industri, dikonversi 20 SKS.
Metode belajar: PjBL (karya nyata), PBL (masalah terbuka), dan Case-Based Learning (analisis kasus)

materi 3
Prompt engineering: prompt yang jelas dan berkonteks menghasilkan output AI yang lebih baik. Strukturnya: Role, Task, Context, Format.
Manfaatnya: performa AI lebih baik, bias dan respons ofensif berkurang, hasil lebih terkontrol dan bisa diprediksi, serta pengalaman pengguna lebih baik.
Git vs GitHub: Git adalah version control lokal yang melacak perubahan file. GitHub adalah platform online untuk menyimpan repo Git dan berkolaborasi.
Alur Git: working directory, staging area, lalu repository.
